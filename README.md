# VDDN RCRDS — free plugins

## HORIZON REVERB 0.1.0
Ten reverbs. Ten worlds. VST3 · AU · JSFX for macOS and Windows.

| | |
|---|---|
| macOS (VST3 · AU) | [HORIZON-REVERB-0.1.0-mac.pkg](HORIZON-REVERB-0.1.0-mac.pkg?raw=1) |
| Windows (VST3) | [HORIZON-REVERB-0.1.0-win.exe](HORIZON-REVERB-0.1.0-win.exe?raw=1) |
| REAPER (JSFX) | [HORIZON-REVERB-0.1.0-jsfx.zip](HORIZON-REVERB-0.1.0-jsfx.zip?raw=1) |

**Mac:** if macOS blocks the installer: System Settings → Privacy & Security → Open Anyway.
**Windows:** if SmartScreen appears: More info → Run anyway.
**JSFX:** unzip and drop the `VDDN` folder into REAPER's `Effects` folder.
