## HORIZON REVERB 0.1.1
Ten reverbs. Ten worlds. VST3 · AU · JSFX for macOS and Windows.

**Black Friday:** free until Nov 30 — click **ACTIVATE** in the plugin and enter `VDDN-FAMILY-2026`.

| | |
|---|---|
| macOS (VST3 · AU) | [HORIZON-REVERB-0.1.1-mac.pkg](HORIZON-REVERB-0.1.1-mac.pkg?raw=1) |
| Windows (VST3) | [HORIZON-REVERB-0.1.1-win.zip](HORIZON-REVERB-0.1.1-win.zip?raw=1) |
| REAPER (JSFX) | [HORIZON-REVERB-0.1.1-jsfx.zip](HORIZON-REVERB-0.1.1-jsfx.zip?raw=1) |

**Mac:** if macOS blocks the installer: System Settings → Privacy & Security → Open Anyway.
**Windows:** unzip and copy the `HORIZON REVERB.vst3` folder into `C:\Program Files\Common Files\VST3`.
**JSFX:** unzip and drop the `VDDN` folder into REAPER's `Effects` folder.
